API Architecture (Free, No Key Needed for Read)

Three APIs — Different Purposes

APIBase URLAuth Needed?Purpose
Gamma APIgamma-api.polymarket.comNO — fully publicMarket metadata, prices, volume, categories
CLOB APIclob.polymarket.comRead: NO / Trade: YESOrder book, midpoints, spreads, place orders
Data APIdata-api.polymarket.comYES — wallet keyYour positions, trade history, P&L
For your morning brief module: The Gamma API is all you need for scanning and analysis. It's free, has no rate limits for reasonable usage, and returns market prices, volume, liquidity, and metadata. You only need CLOB API auth if you want to actually place trades.

Key Gamma API Endpoints

# Get top markets by 24h volume (active, not closed)
GET https://gamma-api.polymarket.com/markets?active=true&closed=false&order=volume24hr&ascending=false&limit=50

# Search markets by keyword
GET https://gamma-api.polymarket.com/markets?active=true&closed=false&tag=politics&limit=20

# Get specific market by slug
GET https://gamma-api.polymarket.com/markets?slug=will-bitcoin-reach-150000-in-march

# CLOB: Get midpoint price (no auth)
GET https://clob.polymarket.com/midpoint?token_id={TOKEN_ID}

# CLOB: Get order book (no auth)
GET https://clob.polymarket.com/book?token_id={TOKEN_ID}

The Weather Edge (Your Best Starting Strategy)

One bot turned $1,000 → $24,000 since April 2025 trading ONLY London weather markets. Another has $65,000 profit across NYC, London, and Seoul weather. This works because weather markets are low-competition niches where professional forecast data is freely available.

How It Works (Step by Step)

  1. Get official forecast: NOAA/NWS API (free, no key) → tells you "NYC high tomorrow: 43°F"
  2. Check Polymarket price: "Will NYC high be 40-45°F?" is trading at 15¢ (market says 15% chance)
  3. Compare: NOAA says 43°F with high confidence → actual probability is ~70-80%
  4. The edge: You're buying a 70%+ probability event for 15¢. Expected value = 0.70 * $1.00 - 0.15 = +$0.55 per share
  5. Execute: Buy shares, wait for resolution, collect $1.00 per correct share
